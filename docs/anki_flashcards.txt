What is Byte-Pair Encoding (BPE)?	A subword tokenization algorithm that begins with a base vocabulary of single bytes (0-255) and iteratively merges the most frequent adjacent pairs into new token IDs until reaching a target vocabulary size.	LLM::Tokenization
Why do modern LLMs like GPT-2 use byte-level BPE instead of word-level tokenization?	Byte-level BPE guarantees that any string in UTF-8 can be tokenized with zero Out-Of-Vocabulary (OOV) errors, while still compressing frequent character sequences into concise token IDs.	LLM::Tokenization
In autoregressive language modeling, why are training targets y shifted by 1 relative to inputs x (y[t] = x[t+1])?	Because the model is trained on next-token prediction: given the context of all tokens up to position t, the objective is to predict the immediate next token at position t+1.	LLM::Data
What is the mathematical formula for Scaled Dot-Product Attention?	Attention(Q, K, V) = softmax((Q @ K^T) / sqrt(d_k)) @ V	LLM::Architecture
Why do we divide by sqrt(d_k) in Scaled Dot-Product Attention?	For large d_k, the dot products grow large in magnitude, pushing the softmax function into regions with extremely small gradients (vanishing gradient problem). Scaling by 1/sqrt(d_k) preserves variance ~ 1.	LLM::Architecture
What is a Causal Mask in decoder-only Transformers?	An upper-triangular matrix of -inf values applied before softmax to ensure token at position t can only attend to positions <= t, preventing the model from 'cheating' by looking at future tokens.	LLM::Architecture
What is the difference between Pre-LayerNorm and Post-LayerNorm in Transformers?	Pre-LayerNorm applies layer normalization BEFORE the multi-head attention and MLP sub-layers (x = x + SubLayer(LN(x))), providing an unimpeded residual stream that makes deep networks significantly more stable to train.	LLM::Architecture
What is Weight Tying in GPT models?	Sharing the weight matrix between the input token embedding layer (wte) and the final linear output projection layer (lm_head). Reduces parameter count and improves representation learning.	LLM::Architecture
What is the purpose of AdamW's decoupled weight decay compared to standard L2 regularization?	In standard Adam, L2 regularization is added directly to gradients, distorting the moving averages. AdamW applies weight decay directly to parameter updates independently of the gradient moving averages.	LLM::Training
Why do we avoid applying weight decay to 1D parameters (biases and LayerNorm weights)?	Biases and normalization scaling factors control shifts and scales rather than model complexity; decaying them to zero constrains the network's dynamic range without helping regularization.	LLM::Training
What is a Cosine Learning Rate Schedule with Linear Warmup?	Learning rate increases linearly from 0 to max_lr over warmup steps (stabilizing early gradient updates), then decays following a cosine curve down to min_lr across remaining iterations.	LLM::Training
What is Gradient Clipping and why is it essential for Transformer training?	It caps the global L2 norm of the gradient vector to a threshold (e.g. 1.0) before the optimizer step, preventing exploding gradients from destabilizing training.	LLM::Training
What does Temperature scaling do during text generation?	It divides raw logits by temperature T before softmax. T < 1.0 sharpens the probability distribution (more deterministic/focused), while T > 1.0 flattens it (more random/creative).	LLM::Sampling
What is Top-K sampling?	A filtering strategy that keeps only the K highest-probability tokens, setting all other logits to -infinity before taking the softmax and sampling.	LLM::Sampling
What is Top-P (Nucleus) sampling?	A dynamic filtering strategy that sorts tokens by probability and keeps the smallest subset whose cumulative probability exceeds threshold P (e.g. 0.9), adapting vocabulary choices based on model confidence.	LLM::Sampling
What is Repetition Penalty in autoregressive generation?	A technique that discounts the logits of tokens that have already appeared in the prompt or generated context, discouraging repetitive loops.	LLM::Sampling
What is the fundamental difference between a Base Model and an Instruction-Tuned (Chat) Model?	A Base Model is a pure text-completer trained on raw continuous text via next-token prediction. An Instruction-Tuned Model has undergone Supervised Fine-Tuning (SFT) on dialogue pairs and RLHF to act as a conversational assistant.	LLM::Concepts
Does turning a base model into a chatbot require massive data centers?	No. Pretraining the base model requires large compute, but Supervised Fine-Tuning (SFT) for chatbot behavior requires only a few thousand conversational pairs and can be executed on a single GPU in hours.	LLM::Concepts
Why does MiniGPT-Em respond to 'What is your name?' with 'My name is, who? My name is, Slim Shady' instead of answering conversationally?	Because it is a base model trained solely on Eminem lyrics; it predicts the statistically most likely continuation in its training universe, treating the input as an opening rap phrase rather than a user question.	LLM::Concepts
How do parameter size and dataset volume affect model output quality?	A ~12.7M parameter model trained for 1k steps learns syntax, vocabulary, and rhythm, but lacks capacity and training steps for complex multi-syllable rhyming schemes or broad world knowledge.	LLM::Concepts
